# 導航／功能盤點（Navigation Inventory）

逐項盤點桌面版與手機版的可達性。桌面＝側邊欄常駐；手機＝底部導航（今天／計畫／
讀書／任務／行事曆）＋左上 ☰ 抽屜（開啟同一個側邊欄，次要頁都在裡面）。

分類：normal（有正常入口）｜deep-link（由某頁深連結進入）｜intentionally-removed
（刻意移除、route 保留供深連結，不restore）。

## 本 PR 對導航的改動
1. **Schedule History**：先前 `schedule-history` view 有 render 但無任何 setter（真正的
   靜默消失）→ 由 Plan 明細「確切安排」區新增「排程紀錄（版本歷史）」深連結修復。
2. **School Assignment**：確認原本可由「任務」頁分頁列進入（非消失）；本 PR 另於側欄
   「學習」補一個直接入口，提高可發現性。
3. 其餘項目經逐一盤點皆有正常入口或既有深連結，無靜默失效或手機消失。
4. **不 restore**：Archive（已正式移除）、Matrix（刻意退出第一層，且不在要求清單內）。
